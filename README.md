# Página Pessoal - Helder Jose Avila

Atividade Prática 2 da disciplina **GAC116 - Programação Web** (UFLA): desenvolvimento de uma página pessoal (portfólio web) utilizando HTML, CSS e JavaScript, em duas versões com frameworks CSS diferentes.

## 🔗 Demo

- **Bootstrap:** https://helderavila-lab.github.io/pagina-pessoal/
- **Tailwind CSS:** https://helderavila-lab.github.io/pagina-pessoal/tailwind.html

## Versões

- [`index.html`](index.html) — versão com **Bootstrap**
- [`tailwind.html`](tailwind.html) — versão com **Tailwind CSS**

As duas versões têm o mesmo conteúdo (interesses, projetos, repositórios do GitHub e contato), variando apenas o framework de estilização.

## Funcionalidades

- Layout responsivo
- Alternância entre tema claro e escuro
- Listagem de repositórios reais do [GitHub](https://github.com/helderavila-lab)

## Estrutura

```
├── index.html          # versão Bootstrap
├── tailwind.html        # versão Tailwind CSS
├── css/
│   ├── style.css         # estilos da versão Bootstrap
│   └── tailwind-style.css # estilos da versão Tailwind
└── js/
    ├── theme.js              # alternância de tema (Bootstrap)
    └── tailwind-theme.js     # alternância de tema (Tailwind)
```
